Topics covered
W1 AI in the Design Process ▾

Topics covered

  • AI design tools overview: Figma AI, Adobe Firefly, Framer AI
  • Generative design and design system automation
  • AI's role in user research and persona generation
  • Ethical considerations in AI-designed interfaces

Learning outcomes

  • Generate 5 UI concepts from a single text prompt
  • Evaluate AI-generated designs against usability heuristics
W2 AI-Powered User Research ▾

Topics covered

  • Automated user interview analysis with NLP
  • Sentiment analysis of app reviews and surveys
  • AI heatmap prediction before usability testing
  • Synthesising research insights with AI

Learning outcomes

  • Analyse 200 app reviews and extract actionable insights
  • Generate a user persona from AI-synthesised research
W3 Wireframing & Prototyping with AI ▾

Topics covered

  • Wireframe generation from sketches and descriptions
  • Framer AI and Relume for rapid prototyping
  • AI-assisted information architecture design
  • Accessibility checking with AI tools

Learning outcomes

  • Build a complete app wireframe from a one-paragraph brief
  • Generate and test 3 navigation structures with AI
W4 Visual Design & Branding with AI ▾

Topics covered

  • AI colour palette and typography recommendations
  • Logo and icon generation with Midjourney and Adobe Firefly
  • Design token generation and design system creation
  • AI-assisted brand guideline development

Learning outcomes

  • Create a full brand identity using AI tools
  • Generate a design system with AI-recommended tokens
W5 Personalisation & Adaptive Interfaces ▾

Topics covered

  • Dynamic UI that adapts to user behaviour with ML
  • Recommendation systems in UI design
  • A/B testing with AI-driven hypothesis generation
  • Contextual interfaces and progressive disclosure

Learning outcomes

  • Design a personalised dashboard that adapts to user roles
  • Run an AI-driven A/B test on a landing page
W6 Conversational UI & AI Feature Design ▾

Topics covered

  • Designing for chatbots, voice assistants, and co-pilots
  • Copilot patterns: suggestions, completions, and commands
  • Error state and fallback design for AI features
  • Trust and transparency in AI-powered products

Learning outcomes

  • Design a conversational onboarding flow
  • Create UI patterns for an in-app AI assistant
W7 Usability Testing & Iteration with AI ▾

Topics covered

  • AI-moderated usability testing platforms
  • Automated session recording analysis
  • Predictive usability scoring
  • Rapid design iteration cycles with AI feedback

Learning outcomes

  • Conduct an AI-moderated usability test with 10 participants
  • Iterate a design 3 times in 48 hours using AI insights
W8 Capstone: AI-Powered Product Design ▾

Topics covered

  • Full product design sprint: research to prototype
  • Presenting design decisions to stakeholders
  • Building a UX portfolio with AI-assisted case studies
  • Final critique and portfolio review

Learning outcomes

  • Deliver a fully designed and prototyped AI-powered product
  • Present a compelling design portfolio
