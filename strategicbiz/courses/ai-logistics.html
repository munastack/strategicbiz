W1 AI Overview in Logistics & Supply Chain ▾

  • Data infrastructure requirements for logistics AI

Learning outcomes

Topics covered

  • Time-series forecasting with ARIMA, Prophet, and LSTMs

  • Integrating forecasts into ERP systems

Learning outcomes

  • Build a demand forecast model for a retail product
  • Reduce stockout rates by 20% in a simulation exercise
W3 Route Optimisation & Last-Mile Delivery ▾

Topics covered

  • Vehicle routing problem (VRP) and AI solvers
  • Real-time traffic integration and dynamic rerouting

Learning outcomes

  • Optimise delivery routes for a fleet of 20 vehicles
  • Compare AI routing vs. manual planning on cost metrics
W4 Warehouse Automation & Computer Vision ▾

Topics covered

  • Automated picking systems and cobots

Learning outcomes

  • Implement a computer vision defect detection prototype
W5 Predictive Maintenance & Fleet Management ▾

Topics covered

  • IoT sensor data and predictive failure models
  • Fleet telematics and driver behaviour AI
  • Maintenance scheduling optimisation
  • Cost-benefit analysis of predictive vs. reactive maintenance

  • Build a predictive maintenance model for trucks
  • Reduce simulated fleet downtime by 30%
W6 Trade Compliance & Customs Automation ▾

Topics covered

  • Build an HS code suggestion tool using NLP

Topics covered

  • Circular economy and reverse logistics AI

Learning outcomes

  • Create a sustainability dashboard for a supply chain
  • Build a supplier risk scoring model
