02. AI Chatbot Engineering

Certified AI Bot Developer — design, build and deploy intelligent conversational agents

8
Weeks
2
Months
16
Learning outcomes
32
Topics covered
W1 Foundations of Conversational AI ▾

Topics covered

  • History and evolution of chatbots
  • Rule-based vs. ML-based vs. LLM-powered bots
  • Architecture overview: NLU, dialogue manager, NLG
  • Key platforms: Dialogflow, Rasa, Botpress, OpenAI

Learning outcomes

  • Map the architecture of three real-world chatbots
  • Set up development environments for Rasa and Dialogflow
W2 Natural Language Processing (NLP) Essentials ▾

Topics covered

  • Tokenisation, stemming, lemmatisation
  • Intent classification and entity recognition
  • Sentiment analysis and context handling
  • Training data collection and annotation best practices

Learning outcomes

  • Train a custom intent classifier with 500+ utterances
  • Build an NER model for a domain-specific use case
W3 Designing Conversation Flows ▾

Topics covered

  • Conversation design principles and UX writing
  • Decision trees, slots, and fallback strategies
  • Multi-turn dialogue and context carryover
  • Handling edge cases: ambiguity, out-of-scope queries

Learning outcomes

  • Design a complete conversation flow with 20+ intents
  • Implement slot-filling for a booking bot
W4 LLM Integration & Prompt Engineering ▾

Topics covered

  • Connecting bots to GPT-4, Claude, and Gemini APIs
  • Prompt chaining and retrieval-augmented generation (RAG)
  • System prompts, personas, and guardrails
  • Token management and cost optimisation

Learning outcomes

  • Build an LLM-powered FAQ bot with RAG
  • Implement prompt guardrails and safety filters
W5 Backend Integration & APIs ▾

Topics covered

  • Webhooks, REST APIs, and database connectivity
  • Authentication: OAuth, JWT, API keys
  • CRM and ERP integration (Salesforce, HubSpot)
  • Payment gateway integration for transactional bots

Learning outcomes

  • Connect a chatbot to a live CRM via REST API
  • Build a transactional bot with payment processing
W6 Multi-Channel Deployment ▾

Topics covered

  • Deploying on WhatsApp Business, Telegram, and Slack
  • Web widget embedding and mobile SDK integration
  • Voice channel integration with Twilio and Alexa Skills
  • Channel-specific UX constraints and adaptations

Learning outcomes

  • Deploy the same bot across three channels simultaneously
  • Configure voice response for a phone-based chatbot
W7 Testing, Analytics & Optimisation ▾

Topics covered

  • Automated testing frameworks for chatbots
  • Key metrics: containment rate, CSAT, fallback rate
  • A/B testing conversation flows
  • Continuous learning and model retraining pipelines

Learning outcomes

  • Build a testing suite with 50+ conversation test cases
  • Create a bot analytics dashboard with actionable KPIs
W8 Certification Project & Ethics ▾

Topics covered

  • AI ethics in conversational agents
  • GDPR, data privacy, and user consent in chatbots
  • Capstone: end-to-end chatbot for a real business case
  • Certification exam preparation and portfolio review

Learning outcomes

  • Submit and defend a production-ready chatbot project
  • Pass the Certified AI Bot Developer assessment
